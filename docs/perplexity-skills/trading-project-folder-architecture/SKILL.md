# Trading Project Folder Architecture

Use this skill when creating, reorganizing, or extending folder structures for trading-related projects inside AI-Agent-Learning-Hub.

Focus on clear separation between project code, raw inputs, processed data, outputs, documentation, scripts, and reusable shared components.

Prefer stable, version-friendly layouts that support Python, ThinkScript, VantagePoint exports, TOS exports, strategy research, and automation workflows.
