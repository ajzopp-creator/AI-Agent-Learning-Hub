# VantagePoint Pattern Matching

Use this skill when analyzing VantagePoint grid data or IntelliScan candidates to compare current stock setups against a catalog of historically profitable patterns.

Focus on short-horizon pattern recognition, typically from 3 trading days to 3 weeks, using feature comparisons, setup ranking, and structured match outputs.

When possible, return pattern identifiers, similarity measures, expected return estimates, hit-rate context, and downside or adverse-excursion context.
