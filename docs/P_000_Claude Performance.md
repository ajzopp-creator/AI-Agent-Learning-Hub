# How to Not Hit Claude's Usage Limit Again

### 1. Shrink Your Files
* **Avoid heavy formats:** PDFs and screenshots consume many credits. Instead, copy-paste text into a plain text file.
* **Crop images:** Only include the specific part of an image that matters for the task.
* **Rule of thumb:** *Smaller file = fewer credits burned.*

### 2. Plan First. Build Last.
* **Refine the goal:** Don't start with complex requests like "make me a spreadsheet." Use the chat to figure out exactly what you want first.
* **Execute once:** Once the plan is clear, then have the AI build the file.
* **Motto:** *Think cheap. Build expensive.*

### 3. Say "Ask Me Questions"
* **Avoid long prompts:** Stop writing 500-word initial prompts.
* **Iterate:** Add "Ask me questions before you start." Then click the options the AI provides.
* **Rule of thumb:** *Clicking costs almost nothing. Typing costs a lot.*

### 4. Edit, Don't Resend.
* **Fix mistakes:** If you made a typo or a mistake in your prompt, don't send a new message. Use the **Edit** button on your existing message.
* **Replace, don't stack:** Regenerating replaces the old version instead of adding to the chat history.
* **Motto:** *Every "no wait, I meant..." makes your chat more expensive.*

### 5. Start Fresh Every 15-20 Messages
* **Context overhead:** Every new message in a long chat forces the model to re-read the entire history, getting expensive fast.
* **Reset:** After 15-20 messages, ask for a summary, copy it, start a new chat, and paste it in.
* **Rule of thumb:** *Short chats = cheap chats.*

### 6. Pick the Right Model
* **Easy stuff:** Use **Haiku** (fast and cheap).
* **Writing/Reports:** Use **Opus** (smart and costly).
* **Code/Charts:** Use **Sonnet** (the middle ground).
* **Motto:** *Don't use a bulldozer to plant a flower.*

### 7. Use Projects for Recurring Files
* **Centralize data:** Stop uploading the same file to every new chat.
* **Project visibility:** Put a file in a "Project" once; every chat inside that project can reference it.
* **Tip:** *Upload once. Use forever.*

### 8. Turn Off What You Don't Need
* **Disable features:** Web search, connectors, and extended thinking all consume extra credits.
* **Streamline:** If you are just writing, turn these features off.
* **Tip:** *Only pay for what you're using right now.*

### 9. Batch + Spread Your Day
* **Monitor the reset:** Claude resets on a rolling 5-hour window. Don't burn all your credits in one morning session.
* **Batching:** Put 3 tasks in 1 message instead of sending 3 separate messages.
* **Tip:** *By the time you're back, your limit has rolled off.*
