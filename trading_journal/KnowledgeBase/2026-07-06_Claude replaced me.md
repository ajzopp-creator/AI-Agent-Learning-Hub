# Step 3: Test my skill.

A Claude skill is activated with a command (the slash **“/”**) + the name of the skill. So here you just start with **/how-to** to turn on the skill.

1. Open a new chat with Claude.
2. Type the command **/how-to**, and you should see my skill.
3. Then add whatever you wish to do with Claude, but don’t know how.
4. Tada! Et voilà.
