Here’s the simple version:  
  
Claude Code is not just a chatbot.  
  
It is more like a tiny coding helper that can read files, write code, check its work, and follow rules.  
  
But the names make it sound harder than it is.  
  
So explain it like this:  
  
💻 Terminal & CLI  
  
This is Claude’s playground.  
  
It is the black screen where you type commands and Claude does the work.  
  
🤖 Auto Mode  
  
This is when Claude keeps going without asking every 10 seconds.  
  
Useful when the job is clear and low risk.  
  
🧠 Plan Mode  
  
This is Claude saying:  
  
“Before I build the Lego castle, here is my plan.”  
  
Use this before big code changes.  
  
✅ Permissions  
  
This is Claude asking:  
  
“Am I allowed to do this?”  
  
It stops risky actions before they happen.  
  
🎒 Context Window  
  
This is Claude’s school bag.  
  
It can only carry so many files, chats, and instructions at once.  
  
→ /compact  
  
This squashes the chat smaller.  
  
Use it when Claude’s school bag is getting too full.  
  
→ /effort  
  
This tells Claude how hard to think.  
  
Low effort for simple fixes.  
High effort for tricky problems.  
  
→ /btw  
  
This is a quick side note.  
  
Use it when you want to tell Claude something without stopping the main task.  
  
→ /loop  
  
This is Claude setting a timer.  
  
It keeps checking the same thing again and again.  
  
📄 [**CLAUDE.md**](https://www.linkedin.com/safety/go/?url=http%3A%2F%2FCLAUDE%2Emd&urlhash=onXc&mt=wh2kw7u3l-Mzwlv3-SqYKu3SFfFgKbjJhC6MLc2DWpOxs8LHG3abU-7n1Jk9LkNarsLnA5hRrNJgo9dD4_qOBoraO-yimCrQ1A73jqNiCNobWso9Fjr-O1xZ3g&isSdui=true)  
  
This is the rule book.  
  
It tells Claude how your project works before it touches the code.  
  
🧰 Skills  
  
These are instruction packs.  
  
Load one, and Claude suddenly knows the right way to do a specific job.  
  
🧑🔧 Sub-agents  
  
These are helper Claudes.  
  
One can check bugs.  
One can write tests.  
One can review the code.  
  
👷 Agent Teams  
  
This is a group project.  
  
Each agent gets one job so the work does not get messy.  
  
🌳 Worktrees  
  
This is a spare copy of your code.  
  
Claude can try things there without breaking the real version.  
  
📸 Git Commits  
  
These are save points.  
  
Like saving a game before fighting the boss.  
  
🔌 MCP Servers  
  
These connect Claude to tools like Notion, GitHub, Slack, or your data.  
  
⚙️ Hooks  
  
These are automatic helpers.  
  
For example, run a code checker every time Claude saves a file.  
  
🗡 Slash Commands  
  
These are shortcuts.  
  
Type one command and Claude knows what job to start.  
  
📝 Custom Commands  
  
These are shortcuts you create yourself.  
  
Teach Claude once, then reuse it every week.  
  
⏰ Claude Routines  
  
These are scheduled jobs.  
  
Claude can run a task while you are asleep.  
  
The point:  
  
You do not need all 20 features today.  
  
Start with these 6:  
  
→ Plan Mode  
→ Permissions  
→ [**CLAUDE.md**](https://www.linkedin.com/safety/go/?url=http%3A%2F%2FCLAUDE%2Emd&urlhash=onXc&mt=jYf8Sy2hVMQ1g77sAsk5WIagNJZQog9ny4lVB-gLhNN3BP7L4vEb3SOCerQJSo_mpHCawWpqEvAMm_sTvNR7elUdNrE90pCNU4TIFmCemq1zC5MzzSBGFe1zHg&isSdui=true)  
→ Git Commits  
→ /compact  
→ Sub-agents  
  
That covers most real work.  
  
The rest matters once your projects get bigger.
