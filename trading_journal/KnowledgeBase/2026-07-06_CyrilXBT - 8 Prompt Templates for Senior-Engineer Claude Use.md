8 PROMPT TEMPLATES THAT TURN CLAUDE INTO A SENIOR ENGINEER INSTEAD OF AN AUTOCOMPLETE. Most people prompt task by task and wonder why the output feels junior. These are structured for the actual roles a senior engineer plays. THE GOAL TEMPLATE FOR EVERYTHING "Goal: \[your task or agreed spec\]. Keep going until the architecture and result meet the bar, not just until it runs. After every meaningful step: real-time test the real thing." PARALLEL END-TO-END GOAL FOR BIG TASKS Write yourself a new end-to-end /goal. Complete the whole plan, not just the next step, until architecture, implementation, tests, review, and result all meet the standard. Split the work and run it in parallel. PRODUCTION-GRADE BUILD Act as a senior engineer shipping something production-ready. Don't jump to code. Analyze requirements first, list edge cases, design the architecture, then build. UNDERSTAND AN UNFAMILIAR REPO AND REFACTOR Act as a senior engineer who just inherited a large unfamiliar codebase. Understand the architecture and data flow first. Then find structural problems, duplicated code, and performance bottlenecks. SENIOR DEBUGGING ENGINEER Act as a senior engineer chasing a bug in production. Read the code carefully, reason step by step, find the root cause, give a robust fix that accounts for edge cases and performance. PERFORMANCE OPTIMIZATION Optimize as a performance engineer. Targets: speed, memory, scalability. Find bottlenecks, inefficient logic, unnecessary re-renders. Return the explanation plus the optimized code. PRODUCTION-GRADE UI COMPONENTS As a senior frontend engineer, build reusable, accessible, production-ready components. Cover loading states, edge cases, responsive layout, accessibility. PUBLISHABLE APIS As an experienced backend engineer, design clean production-ready APIs. Include validation, error handling, clean architecture. Deliver the route design, controller logic, and full implementation. Copy these into your CLAUDE.md. The gap between a junior output and a senior one is almost always the role you assigned, not the model's capability.
