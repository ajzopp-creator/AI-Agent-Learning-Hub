1. Rewrites peh_helper.py to fix the .done vs .py.done naming-drift bug:

   marker at exactly <script>.py.done, but two real completed handoffs

   two functions NOT meant to change (generate_handoff_filenames,
   done_marker_format) are unchanged.

   run_this_E23001_dbcheck (OIL-tag DB check, Tony confirmed answered --
   nothing to migrate), run_this_E23001_update_descriptions (P_910/P_920

   run_this_P300_20260904_095904 (both already had legacy-named .done
   markers -- genuinely completed, just invisible to the buggy checker).

Success criteria: prints old->new line count for the helper rewrite,
confirms the two untouched functions are identical, prints the
pending-handoffs list from the FIXED helper (should now be empty of these
four), lists files archived per target, then "PASS". A .done marker is
written next to this script.

If it fails: read the FAIL output. Likely causes -- an assert tripped

loosen the asserts to force a pass -- report the actual mismatch.
