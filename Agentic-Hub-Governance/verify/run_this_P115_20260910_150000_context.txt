What this script tests:
Writes the P_115 vault audit note for TWLO (write_to_vault "P115"), then
emits the SIGNAL_V2 packet for TWLO via application.emit_signal.emit_signal.
guideline_entry is TWLO's Eddie Z standard breakout point (241.11), stop is
the chart's PA Stop (220.78), target is the chart's T1 Exit (246.73) -- all
three pass SignalV2's price-logic validator (target > entry > stop).

Success criteria:
Script prints "Vault note written: True" (or a truthy path), then
"Signal written: <path>", then "PASS". A .done file is written next to this
script recording the result.

If it fails:
Read the exception in FAIL output. Likely causes: import path wrong (check
sys.path insert matches P_115 python/ folder), SignalV2 validator rejection
(re-check entry/stop/target ordering), or vault_interface write failure
(permissions/schema). Do not change test assertions -- report the actual
error back to Tony rather than loosening the emit_signal call to force a
pass.

AVAH and INCY are deliberately NOT included in this script -- their Eddie Z
breakout entry sits above the chart's T1/T2 exit levels, which would fail
SignalV2's guideline_target > guideline_entry check. Needs Tony's input
(a resistance level above the breakout price) before those can emit.
