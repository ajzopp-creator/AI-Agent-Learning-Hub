## INCIDENT DURING EXECUTION

First SKILL.md write used a PowerShell helper function that emitted status
strings to the output stream alongside its return value. PowerShell folded
both into the content variable, prepending ten status tokens onto line 1 and
destroying the YAML frontmatter opening delimiter. The skill would have
failed to parse and silently stopped triggering.

Caught on readback, repaired same call-sequence, verified clean (390 lines,
no stray tokens, frontmatter intact). All 10 content edits had applied
correctly; damage was confined to line 1.

**Lesson (add to PowerShell I/O patterns):** never `Write-Output` inside a
PowerShell function whose return value is assigned. Status reporting and
return values share one stream. Use `Write-Host`, or collect status into a
variable and emit after assignment.
