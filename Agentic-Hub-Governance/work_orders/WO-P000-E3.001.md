## WHY

Projects completing work orders are leaving downstream projects in a confused
state. Each project that opens a new session must research what prior projects
did before it can proceed -- finding path discrepancies, stale references, and
undocumented decisions along the way. P_300 hit this. P_400 hit this. It will
keep happening unless P_000 owns a completion gate that every WO must pass
before closing.

The root cause is that WO closure has been a single-project act. The closing
project marks its own work OWNER_DONE with no cross-Hub consistency check.
Other projects are not notified. Documentation is not verified. Path references
are not confirmed against Hub standards. The alias `Agentic-Hub-Governance\`
exists but is not consistently used in project docs. The canonical path for
`vault_interface.py` was settled in WO-P000-E2.003 but that decision has not
been propagated to project CLAUDE.md files that reference it.
