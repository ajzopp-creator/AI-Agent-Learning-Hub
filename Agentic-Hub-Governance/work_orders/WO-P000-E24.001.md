## Scope

1. **Schema.** Add `confidence_tier` column to `trades`
   (`CONFIRMED` / `INFERRED` / `UNRESOLVED`, per WO-P000-E22.001 Rule 3).
   Backfill existing rows' tier based on their current `source`/`system`
   values before this column is relied on anywhere.
2. **Resolver reorder.** `system_resolver.py`'s base chain (vault/tracker/
   default) still needs the P_400 shadow-to-live cutover and the ThinkLog-
   live extension described below -- P_820's own override layer
   (`p820_capture.py`/`p820_override.py`) already sits on top of it
   correctly and needs no rebuilding (see correction above). Target
   effective order: P_820 override (already live, unchanged) -> P_400
   vault, cut over from shadow to live -> ThinkLog (extended to the live
   account, absorbing NEXT-3/BACKLOG-8) -> Tracker (demoted, last before
   default) -> `UNRESOLVED`. **The P_400 shadow-to-live cutover is the
   single highest-risk item in this WO** -- it changes what actually gets
   written for live trades, not just how it's labeled. Do not flip
   `shadow_mode` without a separate explicit go-ahead once shadow-
   comparison data (`ShadowTally`) shows the vault agrees with Tracker at
   an acceptable rate. Everything else in this scope item can proceed
   independently of that flip.
3. **Views/exports.** `v_trade_summary` and CSV exports exclude
   `UNRESOLVED` by default; add an explicit include-flag for whole-account
   totals (balance/cash figures must still include everything).
4. **OIL live-data fix (inherited from WO-P000-E23.001's deferred
   item).** Confirm whether any `trades.system = 'OIL'` rows exist
   (the check staged at `run_this_E23001_dbcheck.py` -- run it as part of
   this WO if not already done) and migrate any found to `P_116`.
   `thinklog_override.py`'s docstring currently describes open-vocabulary,
   verbatim tag-to-system-value behavior as a *feature* -- change it so
   `[OIL]` is explicitly rejected/warned rather than silently accepted,
   consistent with WO-P000-E23.001's resolution decision.
5. **Phase 2 backfill.** Re-run attribution for all AJZ6348 and PAPER
   trades since 2026-06-01 under the new chain and confidence-tier logic.
   Genuinely unrecoverable trades marked `UNRESOLVED`, not guessed.
