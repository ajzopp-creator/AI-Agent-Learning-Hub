## WHY

P_300 stamps guideline_entry as the close price at eval time — a reference price,
not an execution target. P_400 had no formal rule for resolving the actual entry
from the live snapshot price. Drift logic treated favorable and adverse drift
symmetrically, and there was no early-return path for entry-missed scenarios.

## WHAT

Three-case entry resolution rule (Section 6.5):
- Favorable (live < guideline): use live price, R:R improves, no block
- Within threshold (0-1.5%): use live price, proceed normally
- Entry missed (adverse drift > 1.5% AND R:R < 2.0): early return BLOCKED via
  RC_ADVERSE_DRIFT; caller writes REVIEWED_NO_TRADE with drop_reason=ENTRY_MISSED
