## WHY

Tony asked for a live dashboard regenerate, then asked to scope PAPER
analysis to 06/01/2026 with no earlier data. Investigation found the date
scope was a literal hardcoded in two separate functions in
`stats_export.py` (PAPER: no floor at all; LIVE: stuck at `2026-01-01`,
not sourced from config), `generate_dashboard.py` had zero CLI parameters
(one hardcoded input path, one hardcoded output file -- could not target
PAPER's export folder at all), and `dashboard_html.py` hardcoded
`"ACCOUNT ...6348"` in the header/footer regardless of which account's
data it was rendering. None of "parameter-driven start date," "recreate
dashboard from any start date," or "paper dashboard" existed in code.

Tony's follow-up question ("if I can control it, why move the live
default?") resolved the one open decision from scoping: `--start-date`
makes the config default just the no-flag fallback, not a permanent
boundary -- `LIVE_ANALYSIS_START_DATE` stays `2026-01-01`, unchanged.

### Found Live -- COALESCE gap (2026-09-19, same session)
First `dashboard --account PAPER` run crashed:
`ValueError: could not convert string to float: ''` in `compute_kpis()`.
Root cause: `export_summary_by_system`'s SQL took `AVG(realized_R)` etc.
with no `COALESCE`, unlike `total_pnl` two lines above it in the same
query (which already had one). A system with only open trades in a
narrow date range (exactly what `--start-date` now makes possible) gets
SQL `NULL` for those averages, which `csv.DictWriter` renders as `''`,
which `float()` then rejects. `dashboard_html.py`'s `_system_rows()` /
`_monthly_rows()` would have hit the identical crash rendering that row.
This bug pre-dated this WO (existed anywhere `total_pnl` used COALESCE
and `avg_R` didn't) but was unreachable before, since every scope was
"all history," which always had at least one closed trade per system.
Fixed at the source: `avg_win`, `avg_loss`, `avg_win_R`, `avg_loss_R`,
`avg_R` (both exports) now `COALESCE(...,0)`, matching the `total_pnl`
convention already used in the same query. Re-ran PAPER dashboard clean
after the fix; live dashboard re-verified unaffected (byte-identical
header/badge text to pre-WO output).
