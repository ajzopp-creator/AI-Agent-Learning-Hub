**Status:** CLOSED

**Depends On:** None

---

## WHY

Only P_300 (`p300-project-context`) and P_020 (`p020-project-context`) have a
project-context skill. P_010, P_115, and P_400 -- P_400 being the most active
domain recently -- start every session with no auto-loading protection layer:
no critical paths, no anti-pattern list, no schema shorthand, no session-start
checklist specific to that project.

This is the gap named directly by the context-engineering review
(2026-07-06 KB article, "Anthropic engineers 8x output"): the three-layer
context stack is global / project / task, and a session missing the project
layer has to guess architecture, conventions, and known failure modes instead
of loading them. P_300 and P_020 already prove the pattern works; the other
three active projects are running without it.

---

## RECOMMENDED FIX

Build three new skill files using `p300-project-context/SKILL.md` as the
structural template (same section order, same density):

1. `.claude\skills\p010-project-context\SKILL.md`
2. `.claude\skills\p115-project-context\SKILL.md`
3. `.claude\skills\p400-project-context\SKILL.md`

Each covers, at minimum:
- Purpose & Pairs With (which docs/SIP/tasks files it pairs with)
- Critical Paths (project root, DB/data paths, interpreter, any project-specific
  path gotchas)
- Anti-Patterns (pull from that project's existing EC log / bug table if one
  exists; otherwise start the table empty and let it grow per the Session
  Close protocol added in WO-P000 system-doc-initializer, 2026-07-06)
- AI Behavioral Rules (Must / Must Not)
- Session-Start Checklist
- Changelog

Do NOT copy P_300-specific content (VantagePoint schema, pattern catalog
mechanics) into the other three -- template the structure, not the substance.

Build order: P_400 first (most active), then P_115, then P_010.

---

## ACCEPTANCE CRITERIA

- Three SKILL.md files exist on disk at the paths above, each following the
  p300-project-context structural pattern.
- Each file's description frontmatter triggers correctly on that project's
  name/keywords (mirrors P_300's trigger list format).
- No P_300-specific substance leaked into the other three files.
- Each skill uploaded live via Customize -> Skills (disk edit alone does not
  activate it -- confirm this step happened, don't assume).
- Completion Gate checklist (WO_COMPLETION_GATE.md) completed, including the
  new Independent Review and known-bugs-test checklist items.
