## WHY

WO-P000-E8.001 set live caps (todo.md ~500 lines / ~100KB dated-log portion;
lessons.md ~40 entries / ~70KB) and closed 2026-08-20 with the trigger
mechanism explicitly left open: "WHO/WHEN notices a live file has crossed

2026-08-29: todo.md was at 1,201 lines / 149KB and lessons.md at 59 entries /
75KB before anyone noticed -- caught only because Claude mentioned it in a
session close-out. Exactly the gap E8.001 described. Three archive passes

anything but a person happening to look.

## SCOPE

Add **SIP Step 1B -- Working-State Size Reminder** immediately after Step 1A,
same contract as 1A: reads file metadata via `windows-mcp:FileSystem`
`mode=info` (no Python subprocess), compares to the E8.001 caps, prints a
one-line reminder, **never HALTs**.

- `todo.md` > 500 lines or > 100KB -> `REMINDER: tasks/todo.md is <N> lines
  / <KB> -- archive pass due (WO-P000-E8.001).`
- `lessons.md` > 40 entries or > 70KB -> same shape. Entry count = lines
  matching `^#{2,3} (M|O|S)-\d+`.
- Under cap -> no output.

Deliverables: SIP text edit (v3.5 -> v3.6), `p300-project-context` SKILL
Session-Start Checklist line, one `tasks/todo.md` note. No Python.

## NOT IN SCOPE

- The archive roll itself (routine maintenance under E8.001, done 2026-08-29
  via `verify\run_this_P300_20260829_104500.py`).
- Auto-archiving. The nudge reminds; a person or a deliberate script rolls.
- Hub-wide rollout -- P_000's call after P_300 proves the shape.
