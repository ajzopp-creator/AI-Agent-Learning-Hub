## Why this WO exists

Z_SCORE_INTEGRATION_SPEC.md and FEATURES_ROADMAP_2026.md (Feature 4) define a
formal 3-phase rollout for the Regime Council Z-score indicator:

- Phase 1 Pilot: Sept 1-15, 2026 -- parallel tracking only, 5 trades, does not
  change verdicts. Review Schedule: **Weekly** during Phase 1.
- Phase 2 gate: **user approval required before Sept 16, 2026 start.**
- Phase 3 gate: user approval required before Oct 1, 2026 start.
- Sunset clause: if no improvement shown by end of Q3 2026, drop the feature
  and return to the 27-column system.

Parallel tracking is already live -- ways-of-working.md's "Regime Council
Z-scores: log all 7 raw Z-scores + sumZZ + Regime label in Comments on every
row" convention is the Phase 1 mechanism, and rows have been logged this way
in live sessions (e.g. 2026-09-09: QMCO, RPD, S, SGML, SVV, MRNA, RBLX). But
no work order ever existed to carry the weekly-review cadence or the Sept 16
/ Oct 1 approval gates -- flagged live by Tony 2026-09-09 after a P_115
session had zero open WOs despite an active pilot with a mandated review
schedule.

## Scope

- Track Phase 1 pilot rows logged via the Comments-field convention.
- Capture Z-score data (all 7 raw Z-scores + sumZZ + Regime label) on EVERY
  row logged during Phase 1 -- BUY/ASYM/PASS alike, chart or no-chart alike.
  Decided 2026-09-15 after the 9/10-9/14 capture gap (see Status Log) showed
  an unstated BUY/ASYM-vs-PASS carve-out was never actually specified
  anywhere, which is how the gap happened silently in the first place. No
  carve-outs going forward, even for bulk no-chart PASS screens.
- Surface a weekly review each Sunday (or nearest session) during Phase 1:
  sumZZ/regime distribution so far, any GREEN/YELLOW/RED pre-screen read
  against the actual PASS/BUY verdicts logged, no verdict changes.
- At the Sept 16, 2026 gate: summarize Phase 1 findings, do NOT proceed to
  Phase 2 (active GO/NO-GO filtering) without Tony's explicit approval per
  the spec's Approval Required section.
- At the Oct 1, 2026 gate: same, for Phase 3 full integration.
- If Q3 2026 ends with no demonstrated improvement (win-rate delta or time
  savings per the roadmap's Decision Matrix), close this WO with a DROP
  recommendation rather than let it linger open.

## Not in scope

- Adding the 35-column schema (columns 28-35) -- that's Phase 3, conditional
  on Phase 1/2 passing their gates. Current logging stays in the 27-column
  Comments field per ways-of-working.md.
- Changing any BUY/PASS/ASYM verdict based on Z-score reads -- Phase 1 is
  observation-only by design.
