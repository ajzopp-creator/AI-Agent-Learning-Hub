---

## WHY

After every evaluate, Tony must manually construct and run a Python script to
write the P400 record via write_to_vault(). This is manual effort that should
not exist. The EvaluationResult already contains every field needed for the
record. The write should happen automatically as part of the evaluate command.

Discovered: 2026-06-15 (CMCSA paper trade session).

---

## WHAT

After council verdict is returned in cmd_evaluate(), call write_to_vault("P400")
automatically using fields from EvaluationResult. No separate command, no manual
script. Record is written as part of every evaluate run.

Fields to write:
  signal_date       from packet.signal_metadata.session_date
  run_date          today
  run_ts            now (ISO)
  written_by        "P_400/cli_evaluate"
  ticker            result.symbol
  council_verdict   result.verdict
  lifecycle_status  "PAPER" if paper mode, else "SUBMITTED" (after Schwab submit)
                    "PENDING" until order confirmed
  risk_mode         result.posture.risk_mode
  entry_price       snapshot price
  stop_price        effective_stop
  target_1          packet.guideline_target
  position_size     result.sizing.shares (or qty_override if set)
  p115_linked       True if packet.signal_source == "P_115"
  p300_linked       True if packet.signal_source == "P_300"
  drop_reason       set for REVIEWED_NO_TRADE / BLOCKED dispositions

BLOCKED and REVIEWED_NO_TRADE records also written automatically with
appropriate lifecycle_status = "DROPPED" and drop_reason populated.
