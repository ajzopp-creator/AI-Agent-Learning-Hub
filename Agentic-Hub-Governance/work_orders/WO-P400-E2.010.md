## WHY

The signals inbox (`trading_journal\TradeOrderManagement\signals\`) accumulates
every JSON packet ever emitted and never cleans up. screen-all re-reads the
entire folder every run, mixing today's fresh signals with weeks of stale ones.
Once a signal is evaluated and a terminal P400 disposition is recorded
(APPROVED, BLOCKED, REVIEWED_NO_TRADE), the JSON has served its purpose.

Tony will manually zip and move the existing 74 packets once. Every signal
evaluated going forward is auto-archived immediately after evaluation completes.

---

## DESIGN

- After `evaluate_signal()` returns any terminal result, the source JSON is
  appended to a monthly zip at:
  `trading_journal\TradeOrderManagement\signals\processed\YYMM_ProcessedJson.zip`
  (e.g. `2606_ProcessedJson.zip` for June 2026)
- If the zip already exists for the month, the file is appended (not replaced)
- The original JSON is deleted from the inbox after successful zip write
- Archive is a side effect of evaluate — no separate CLI command needed
- Source packet path is resolved from SIGNALS_DIR + filename pattern at call time
