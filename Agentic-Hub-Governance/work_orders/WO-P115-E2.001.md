# WO-P115-E2.001 -- Stop Field Enrichment: Chart-Derived Levels for P_400 Quant Gate

**Status:** CLOSED
**Owner:** Claude
**Affects:** P_400
**Depends On:** --

---

## WHY

P_115 signals hit P_400's STOP_TOO_TIGHT gate because structural stops derived
from chart analysis (support levels, consolidation bases, pattern invalidation
points) are frequently tighter than P_400's 1x ATR minimum. P_400 blocks valid
setups before they reach the Council.

The fix is to enrich each SIGNAL_V2 packet with three stop fields so P_400 can
select the level that clears its Quant gate without exceeding risk parameters:

  - atr_adjusted_stop       entry - 1x ATR (P_400 primary Quant-gate input)
  - intelliscan_support_1   chart structural stop (primary: support level,
                            consolidation base, or pattern invalidation point)
  - intelliscan_support_2   secondary structural level (next major support
                            below S1 if identifiable; else None)

Field names are identical to P_300's output so P_400's gate logic requires
no changes. P_115 populates them from chart-derived values (not IntelliScan XLSX).

---

## SCOPE

1. Add three new optional fields to signal_builder.build_record():
     atr_adjusted_stop: float | None
     intelliscan_support_1: float | None
     intelliscan_support_2: float | None

2. Compute atr_adjusted_stop in emit_signal.py:
     atr_adjusted_stop = guideline_entry - atm_at_signal
     (atm_at_signal is ATR(14) already accepted by emit_signal)
     If atm_at_signal is None -> atr_adjusted_stop = None

3. Accept intelliscan_support_1 and intelliscan_support_2 as optional params
   in emit_signal.emit_signal(). Caller supplies chart-derived levels.
   Default = None (non-blocking when no secondary level is identifiable).

4. Pass all three fields through to build_record() and into the emitted dict.

5. Update config.py with field name constants if needed for consistency.

---

## OUT OF SCOPE

- IntelliScan XLSX / intelliscan_reader.py (P_115 does not use IntelliScan)

  with these fields as null remain valid)

| intelliscan_support_1 | Chart structural stop | Support, base, or invalidation point |
| intelliscan_support_2 | Next major support below S1 | None if not identifiable |

## ACCEPTANCE CRITERIA

- signal_builder.build_record() includes all three stop fields in output dict
- emit_signal.emit_signal() accepts and passes all three stop params
- atr_adjusted_stop computed correctly when atm_at_signal is provided
- All three fields are None (not absent, not zero) when not available
- Existing emit_signal callers with no new params continue to work (defaults)
- Live signal JSON shows all three fields populated on a test emit
