## WHY

Surfaced during a 2026-08-20 session while trying to hand Tony a `cli.py balance`
command -- that command doesn't exist (see Correction Note below). Working the
real entry point instead (`cli.py --account AJZ` -> `run_balance_command()`),
`pull_balance()`'s Cash Available for Trading came back "N/A" on a live pull.
Traced to `infrastructure/schwab_balance_pull.py`: the extraction only read
`cashAvailableForTrading`; Schwab's response for this margin account does not
always populate that key -- `availableFunds` carries the same figure when it
is absent.

## FIX -- 2026-08-20

`pull_balance()`'s `cash_available` extraction changed to:
`curr.get("cashAvailableForTrading") or curr.get("availableFunds")`
No other field in `pull_balance()` changed -- `buying_power`, `total_value`,
`start_of_day_value`, and `day_pnl` extraction lines are untouched.

## Correction Note

Same 2026-08-20 session: the CLI command surface was misremembered as having
a standalone `balance` subcommand (`cli.py balance`). It doesn't -- balance
pulls run through `cli.py --account AJZ` -> `run_balance_command()`. Corrected
same-session in `p020-project-context`'s Canonical Paths section so the wrong
command surface doesn't get handed to Tony again.
