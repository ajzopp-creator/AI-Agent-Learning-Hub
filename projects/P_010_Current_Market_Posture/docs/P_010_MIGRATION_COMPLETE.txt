  • Check "risk_mode" value (FULL/HALF/OFF)
  • Apply to P_115/P_118 position sizing
  • Use 100% sizing if FULL, 50% if HALF, 0% if OFF

AFTERNOON (2:00 PM or Later):
────────────────────────────────────────────
Location: C:\Users\Trader\AI-Agent-Learning-Hub\projects\P_010_Current_Market_Posture

Command:
  .\run_intraday_vp_check.bat

This will:
  1. Load grid_snapshot_latest.json (from 9:30 AM)
  2. Fetch current SPY/QQQ prices
  3. Validate prices vs VP predicted bands
  4. Calculate deviation percentages
  5. Determine intraday adjustment (NONE/HALF/REDUCED)
  6. Create outputs/intraday_vp_check_YYYYMMDD_HHMMSS.json

Files Created:
