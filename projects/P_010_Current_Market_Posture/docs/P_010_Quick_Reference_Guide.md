## PURPOSE

P_010 provides daily market posture assessment using VantagePoint predictions to determine appropriate risk levels. This system outputs a **risk recommendation** that trading systems **interpret with documented override logic**.

---

## RISK MODE VALUES

### Morning Baseline (9:30 AM)
Generated by `P_010_daily_posture.bat` → `P_010_daily_posture_v4.py`

| Risk Mode | Avg Posture Range | Market Condition |
|-----------|-------------------|------------------|
| **FULL** | ≥1.0 | Bullish trend confirmed |
| **HALF** | 0.0 to <1.0 | Neutral/weak trend |
| **OFF** | <0.0 | Bearish/correction mode |

### Intraday Adjustment (2:00 PM+)
Generated by `P_010_run_intraday_vp_check.bat` → `P_010_intraday_vp_check_v4.py`

| Adjustment | Condition | Meaning |
|------------|-----------|---------|
| **NONE** | Prices within PRANGE bands | Morning assessment still valid |
| **HALF** | One symbol outside bands (>2% deviation) | Moderate risk reduction needed |
| **REDUCED** | Both outside OR severe deviation (>5%) | Significant risk reduction needed |

### Final Risk Mode Calculation
```
IF intraday_adjustment exists:
    final_mode = MIN(risk_mode, intraday_adjustment)
ELSE:
    final_mode = risk_mode

Risk Hierarchy (most restrictive wins):
    OFF < REDUCED < HALF < NONE < FULL
```

## POSITION SIZING INTERPRETATION

### ⚠️ CRITICAL: P_010 Provides Recommendations, Trading Systems Apply Overrides

P_010's risk modes are **recommendations**, not absolute blocks. Trading systems apply the following interpretation logic:

### FULL Mode (avg_posture ≥1.0)
**P_010 Signal:** "Green light for aggressive positioning"

**Trading System Behavior:**
- Position Sizing: 100% (standard $525 risk or tiered in hot markets)
- Warnings: None
- Implementation: Normal three-gate sizing

**Hot Market Escalation (avg_posture >1.08):**
- Tiered risk by HybridTier:
  - HT 6: 2.0% = $700
  - HT 7: 3.0% = $1,050
  - HT 8: 4.0% = $1,400
  - HT 9+: 5.0% = $1,750
- AsymmetricSetups: Treat as HT 6 → 2.0%

---

### HALF Mode (0.0 ≤ avg_posture <1.0)
**P_010 Signal:** "Neutral market - reduce conviction"

**Trading System Behavior:**
- Position Sizing: 50% multiplier ($525 × 0.5 = $262.50)
- Warnings: ⚠️ "Neutral market - reduced confidence"
- Implementation: Apply 0.5× multiplier to Gate 1 (risk-based sizing)

**Example:**
```
Standard Risk: $525 ÷ $5 stop distance = 105 shares
HALF Mode: $262.50 ÷ $5 stop distance = 52 shares (reduced)
```

---

### OFF Mode (avg_posture <0.0)
**P_010 Signal:** "Don't trade longs - market is bearish"

**Trading System Override:**
- Position Sizing: **STILL CALCULATED** with 50% multiplier
- Warnings: 🔴 **"CORRECTION MODE - High risk of failure"**
- Implementation: Show position sizing with prominent warnings

**Why the Override?**
1. **Educational Value:** User can see proper sizing if they choose to trade
2. **User Autonomy:** Final execution decision remains with user
3. **Simulation Capability:** Allows "what if" analysis without commitment
4. **Transparency:** Full calculation shown with appropriate risk disclosure

**Example Output:**
```
⚠️ CORRECTION MODE ACTIVE ⚠️
P_010 Recommendation: OFF (don't trade longs)
Market Posture: -4.45% (bearish)

POSITION SIZING (For Simulation/Educational Purposes):
Risk Multiplier: 0.5× (defensive)
Effective Risk: $525 × 0.5 = $262.50
Position: 109 shares @ $15.93 = $1,736

🔴 WARNING: Breakout probability 40-60% vs 70% in rally
🔴 WARNING: Execute with extreme caution or sit in cash
🔴 WARNING: Eddie Z Rule - "Avoid breakouts during distribution"

Final Decision: USER DISCRETION
```

## VALIDATION RULES

### Morning Calculation
```
Medium_Term_Diff = (predicted_close - current_close) / current_close × 100
Long_Term_Diff = similar calculation with different timeframe

Posture_Score = (Medium_Term_Diff + Long_Term_Diff) / 2

IF Posture_Score >= 1.0:  risk_mode = "FULL"
IF 0.0 <= Posture_Score < 1.0:  risk_mode = "HALF"
IF Posture_Score < 0.0:  risk_mode = "OFF"
```

### Intraday Validation
```
Price_Within_PRANGE = (predicted_low <= current_price <= predicted_high)

Both symbols in PRANGE:  intraday_adjustment = "NONE"
One symbol outside (>2%):  intraday_adjustment = "HALF"
Both outside OR >5% deviation:  intraday_adjustment = "REDUCED"
```

## CRITICAL NOTES

### For Traders
1. **P_010 recommends, YOU decide** - Final execution is always your call
2. **OFF mode ≠ absolute prohibition** - It's a strong warning, not a block
3. **Cash is a position** - When P_010 says OFF, sitting out is often the best trade
4. **Breakout probability matters** - 40% success in CORRECTION vs 70% in RALLY
5. **Eddie Z wisdom** - "Avoid breakouts during distribution phase"

### For System Developers
1. **ALWAYS read P_010_RiskConfig.json** at session start
2. **Apply final_mode = MIN(risk_mode, intraday_adjustment)** when both present
3. **Display market context** in all position sizing outputs
4. **Show warnings prominently** in CORRECTION mode
5. **Document override logic** - Users need to understand "why position sizing when OFF?"

### For Documentation
1. **This override logic is intentional** - Not a bug, it's a feature
2. **User autonomy is paramount** - System advises, user commands
3. **Educational value preserved** - Users learn proper sizing even when not trading
4. **Transparency over restriction** - Better to show calculation + warning than hide it

## TROUBLESHOOTING

### File Not Found
```
Error: P_010_RiskConfig.json not accessible
Action: Fallback to standard risk (1.5% = $525)
Note: Display warning that posture data unavailable
Continue: With standard parameters
```

### Stale Data
```
Check: "timestamp" field in JSON
Warning: If timestamp > 24 hours old
Action: Notify user to run morning batch
Fallback: Use data with staleness warning
```

### Invalid Risk Mode
```
Valid values: "FULL", "HALF", "OFF"
If other value: Default to "HALF" (conservative)
Log: Error to system corrections log
```
