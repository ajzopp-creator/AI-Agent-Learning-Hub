TROUBLESHOOTING INITIALIZATION
================================================================================

Issue: "Grid XML not found"
  ? Check: data/excel_exports/ has both SPY and QQQ files
  ? Verify: Filenames exactly match:
      History Grid (SPY)_v3.xlsx
      History Grid (QQQ)_v3.xlsx
  ? Export fresh Grid files from ThinkorSwim

Issue: "Python/yfinance error"
  ? Check internet connection
  ? Verify: pip list | findstr yfinance
  ? Install: venv\Scripts\pip.exe install yfinance

Issue: "No files created"
  ? Check: logs/P_010_Daily_*.log for errors
  ? Verify: Batch file paths correct
  ? Run: python scripts directly to see errors

Issue: "Old Grid dates"
  ? Grid XML not updated from TOS
  ? Export fresh Grid files (6:30 PM daily)
  ? Verify export location

Issue: "Intraday can't load snapshot"
  ? Morning system must run first
  ? Run: INIT daily before INIT intraday
  ? Verify: grid_snapshot_latest.json exists
