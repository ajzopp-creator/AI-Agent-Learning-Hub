================================================================================
MORNING SYSTEM (9:30 AM)
================================================================================

Script: P_010_daily_posture_v3.py
Batch:  P_010_daily_posture.bat

WHAT IT DOES:
1. Reads Grid XML files from data/xml_exports/
   - History Grid (SPY)_v2.xml
   - History Grid (QQQ)_v2 .xml

2. Extracts latest Grid record (most recent date)
   - Close price
   - Predicted High/Low (PRANGE)
   - Medium/Long term differences
   - Other VP indicators

3. Calculates market posture FROM GRID DATA
   - Posture = (Medium_Diff + Long_Diff) / 2.0
   - SPY posture
   - QQQ posture
   - Average posture

4. Determines risk mode
   - Avg ≥ 1.0  → FULL  (100% position sizing)
   - Avg ≥ 0.0  → HALF  (50% position sizing)
   - Avg < 0.0  → OFF   (0% position sizing)

5. Creates TWO files:

   A. grid_snapshot_latest.json (intermediary)
      Purpose: Used by intraday checks
      Contains: Grid close, PRANGE, postures
      Location: Root directory

   B. P_010_RiskConfig.json (PRIMARY OUTPUT)
      Purpose: Read by P_115/P_118 for position sizing
      Contains: Risk mode, postures, Grid dates
      Location: Root directory
      Backup: data/snapshots/P_010_RiskConfig_YYYYMMDD_HHMMSS.json

INTRADAY SYSTEM (2:00 PM+)
================================================================================

Script: P_010_intraday_vp_check_v3.py
Batch:  P_010_run_intraday_vp_check.bat

WHAT IT DOES:
1. Loads grid_snapshot_latest.json (from 9:30 AM)
   - Gets Grid close price
   - Gets Grid PRANGE (pred_high, pred_low)

2. Fetches current live price from yfinance
   - SPY current price
   - QQQ current price

3. Compares Grid Close → Current Price
   - Calculates % price movement
   - Shows: $[grid_close] → $[current] (+X.XX%)

4. Validates Current Price vs PRANGE
   - Is current price within Grid predicted bands?
   - If outside: How much deviation?
   - Above band, below band, or in band?

5. Determines intraday adjustment
   Rules:
   - Both in band                           → NONE
   - One out with >2% deviation             → HALF
   - Both out OR any >5% deviation          → REDUCED

6. Creates timestamped output file
   outputs/intraday_vp_check_YYYYMMDD_HHMMSS.json

Apply: MIN(morning_risk_mode, intraday_adjustment)

POSITION SIZING LOGIC:
Morning Risk Mode + Intraday Adjustment → Final Sizing

FULL + NONE     → 100% sizing
FULL + HALF     → 50% sizing
FULL + REDUCED  → 25% sizing
HALF + NONE     → 50% sizing
HALF + HALF     → 50% sizing
HALF + REDUCED  → 25% sizing
OFF  + ANY      → 0% sizing
