Before you start: Phase 3C must be complete and you must have run python cli.py export at least once so the CSV files exist. Check that these two files are present before opening Excel: ...\P_020_AJZStrategies_PerformanceAnalysisSystem\data\exports\P_020_options_export.csv ...\P_020_AJZStrategies_PerformanceAnalysisSystem\data\exports\P_020_stocks_export.csv

What Power Query does

Power Query connects your Excel master file directly to a CSV file on disk. When you click Refresh All, Excel reads the latest CSV and updates the Trade Log sheet automatically — no copy, no paste, no formula overwrites. Your Dashboard formulas keep working because they still point to the same Trade Log sheet, just now populated by Power Query instead of by hand.

Part 1 — Options master file

File to open

...\P_020_AJZStrategies_PerformanceAnalysisSystem\data\exports\P_020_Master_Query_2026_AJZ_Strategies_Options_Analytics_V1.xlsx

Step 1 — Open the file and go to Trade Log 2026 sheet

1
Open the Options master file in Excel.
2
Click the Trade Log 2026 tab at the bottom.
3
Click on cell A1 to make sure you're at the top of the sheet.

Step 2 — Create the Power Query connection

4
Click the Data tab in the Excel ribbon.
5
Click Get Data → From File → From Text/CSV.
6
Navigate to the exports folder and select: ...\data\exports\P_020_options_export.csv
7
Excel opens a preview window. Verify the columns look correct — Symbol, System, asset_type, open_date, etc. Then click Transform Data (not Load).

Step 3 — Configure in Power Query Editor

8
The Power Query Editor opens. In the top-left, rename the query from P_020_options_export to OptionsData by clicking the name and typing the new one.
9
Check the column headers in row 1 are being used as headers. If not: click Home → Use First Row as Headers.
10
Click Close & Load To… (the dropdown arrow next to Close & Load).

Step 4 — Load to existing sheet

11
In the Import Data dialog that appears:
• Select Table
• Select Existing worksheet
• Click the small grid icon and select cell A1 on the Trade Log 2026 sheet
• Click OK
12
Excel loads the CSV data into the Trade Log 2026 sheet starting at A1. Your header row and trade data will appear.
Important: Power Query will overwrite rows starting at A1 on each refresh. This is correct — the CSV is the source of truth. Do NOT manually type trade data into the Trade Log 2026 sheet anymore. All data now comes from SQLite via the CSV export.

Step 5 — Test the refresh

13
Click the Data tab → Refresh All. The trade data refreshes from the CSV in seconds.
14
Click the Dashboard tab and confirm the formulas are calculating correctly with the loaded data.
15
Save the file — Ctrl+S. Save as .xlsx (not .csv).

Troubleshooting

ProblemFix
Power Query says "file not found" on refresh Run python cli.py export first to generate the CSV. Then refresh.
Dashboard shows #REF! or zeros after refresh The Power Query table may have loaded to a different cell. Check that data starts at A1 on the Trade Log sheet. Edit query → Close & Load To → re-specify A1.
Column headers changed after refresh The CSV column names changed. Check csv_exporter.py — column names in the export must match what the Dashboard formulas reference.
Old trade data still showing after refresh Click Data → Refresh All again. If still stale, check that cli.py export ran successfully and the CSV timestamp updated.
Power Query connection lost after moving files Open Power Query Editor → Data Source Settings → change the CSV path to the new location.
