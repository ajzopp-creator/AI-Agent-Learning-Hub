# P_005: Local LLM Core

Enterprise-grade local LLM runtime, tool orchestration engine, and benchmarking suite for LM Studio.

## Quick Start
`powershell
# Run tests
python -m pytest python/tests -v

# Run benchmark
python python/cli.py --bench

# Interactive REPL
python python/cli.py --chat
`
