## 2. What Each Folder Is For

| Folder / Element | Purpose | Description |
| :--- | :--- | :--- |
| 📂 **00 - Inbox** | Capture everything. | Process it later. |
| 📂 **01 - Daily** | Daily notes, logs, and reflections. | Structured by year (e.g., 2024, 2025). |
| 📂 **02 - Notes** | Evergreen notes. | Organized by topic (Concepts, People, Places, Ideas). |
| 📂 **03 - Projects** | Active projects. | Plans, tasks, and deadlines. |
| 📂 **04 - Resources** | References. | Links, articles, and tools. |
| 📂 **05 - Archive** | Completed or rarely used items. | Vault maintenance cleanup destination. |
| 🔗 **MOCs** | Maps of Content. | Connect big ideas. See the big picture. |

---

## 3. Principles That Keep You Finding

* 📁 **Use a clear structure**
    * Everything has a home. No more guessing.
* 🏷️ **Use tags intentionally**
    * Add tags that help you *find*, not just collect.
* 🌿 **Link everything**
    * Connect notes as you go. Build your knowledge graph.
* 🔍 **Name clearly**
    * Use descriptive, consistent note titles.
* 🗑️ **Review and clean**
    * Regularly archive or delete what you no longer need.
