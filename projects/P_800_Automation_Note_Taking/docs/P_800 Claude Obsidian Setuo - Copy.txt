## **1. The Problem: Why Most “Second Brains” Fail**
Most people lose **30–40 minutes per Claude session** re‑explaining context   [Current page](citation-section://89304731/2).  
This compounds into **a full workday per week** lost to repetition.

Common failure modes:

- Systems are designed for **input**, not **output**   [Current page](citation-section://89304731/10)  
- Notes accumulate but **don’t talk back**  
- Maintenance becomes overwhelming  
- No mechanism to surface what matters today  
- No reason to return to the vault

A second brain that never speaks back is just an organized forgetting machine.

## **2. The Architecture: Four Layers, One Direction**
Every tool serves exactly one function. No overlap. Flow is one‑way only   [Current page](citation-section://89304731/18).

### **Layer 1 — Capture**  
Zero friction. Everything in, no manual effort.

### **Layer 2 — Pipeline (N8N)**  
Routes captures to the correct vault folder.

### **Layer 3 — Storage (Obsidian)**  
Markdown files = permanent ground truth.

### **Layer 4 — Intelligence (Claude)**  
Reads vault → connects → briefs → writes.

Skipping any layer degrades the entire system.

## **3. Capture Layer: Zero Friction or the System Breaks**
Capture must be effortless, or the system dies under real cognitive load   [Current page](citation-section://89304731/13).

## **4. Vault Structure: Five Folders, One Rule**
Organize by **type**, not topic — this is the key that enables Claude to find connections automatically   [Current page](citation-section://89304731/42).

```
your-vault/
  00-INBOX/        # everything lands here first
  01-CAPTURES/     # processed highlights, articles, clips
      observations/
      reactions/
      patterns/
      questions/
      numbers/
  02-CONNECTIONS/  # insights synthesized from 2+ notes
  03-BRIEFS/       # content ready to write
  04-PUBLISHED/    # archived content + performance data
  05-CLAUDE/       # CLAUDE.md + skills
```

**One rule:**  
When in doubt, put it in **INBOX**   [Current page](citation-section://89304731/44).

## **6. Skills: The Four Automations That Run Everything**
Skills live in `05-CLAUDE/skills/` and are invoked by name.

### **Skill 1 — Process Inbox**
Trigger: **“process my inbox”**   [Current page](citation-section://89304731/124)

Steps:
1. Read every note in `00-INBOX/`
2. For each note:
   - Determine correct CAPTURES subfolder  
   - Sharpen into one punchy sentence  
   - Add exactly **three tags**  
   - Move to correct folder  
3. Report:
   - Total notes processed  
   - Patterns noticed  
   - One connection worth exploring  

Quality bar:  
A stranger should understand the sharpened note without extra context   [Current page](citation-section://89304731/127).
